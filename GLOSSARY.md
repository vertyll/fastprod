# Glossary

Terms the documentation uses, the standard each one comes from, and where it is explained.

| Term                       | Meaning                                                                                                        | Standard                                                                                 | Explained in                                                                                     |
|----------------------------|----------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| Access token               | Short-lived JWT (five minutes) that authorizes one API request.                                                | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-1.4) §1.4                      | [Authentication: Calls to the back-end](docs/authentication.md#calls-to-the-back-end)            |
| Audience (`aud`)           | The token claim naming who the token is for; a token for another audience is refused.                          | [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519#section-4.1.3) §4.1.3                  | [Authentication: Calls to the back-end](docs/authentication.md#calls-to-the-back-end)            |
| Authorization code flow    | Sign-in by redirecting to Keycloak and exchanging the returned code for tokens on the server.                  | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.1) §4.1                      | [Authentication: Signing in](docs/authentication.md#signing-in)                                  |
| BFF (backend for frontend) | The server signs the user in and keeps the tokens; the browser holds only a session cookie.                    | —                                                                                        | [Authentication](docs/authentication.md)                                                         |
| End-session endpoint       | Keycloak's logout address the browser is sent to, which ends the Keycloak session.                             | [OIDC RP-Initiated Logout](https://openid.net/specs/openid-connect-rpinitiated-1_0.html) | [Authentication: Signing out](docs/authentication.md#signing-out)                                |
| ICU MessageFormat          | The message syntax of the catalog, with plural rules for Polish.                                               | [ICU MessageFormat](https://unicode-org.github.io/icu/userguide/format_parse/messages/)  | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)            |
| ID token                   | Token describing who signed in, issued with the access token.                                                  | [OpenID Connect Core 1.0](https://openid.net/specs/openid-connect-core-1_0.html)         | [Authentication: Signing in](docs/authentication.md#signing-in)                                  |
| JWKS                       | Keycloak's published public keys, used to verify a token's signature.                                          | [RFC 7517](https://www.rfc-editor.org/rfc/rfc7517)                                       | [Authentication: Calls to the back-end](docs/authentication.md#calls-to-the-back-end)            |
| JWT                        | Signed JSON token; the access token is one.                                                                    | [RFC 7519](https://www.rfc-editor.org/rfc/rfc7519)                                       | [Authentication: Calls to the back-end](docs/authentication.md#calls-to-the-back-end)            |
| Keycloak realm             | The Keycloak tenant that holds this application's users, roles and clients.                                    | —                                                                                        | [Authentication](docs/authentication.md)                                                         |
| Message key                | A key of the translation catalog sent instead of prose; the client renders it in the reader's language.        | —                                                                                        | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)            |
| PKCE                       | A one-time secret that ties the returned code to the browser that started the sign-in.                         | [RFC 7636](https://www.rfc-editor.org/rfc/rfc7636)                                       | [Authentication: Signing in](docs/authentication.md#signing-in)                                  |
| Problem document           | The JSON body of every refusal: status, a message key and its arguments.                                       | [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)                                       | [Architecture: Errors and translations](docs/architecture.md#errors-and-translations)            |
| Refresh token              | Long-lived token the server trades for a new access token; Keycloak rotates it on every use.                   | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-1.5) §1.5                      | [Authentication: The session and refreshing](docs/authentication.md#the-session-and-refreshing)  |
| Refresh token rotation     | Every refresh returns a new refresh token and invalidates the old one; replaying a spent one ends the session. | —                                                                                        | [Authentication: The session and refreshing](docs/authentication.md#the-session-and-refreshing)  |
| Resource server            | The back-end: it accepts a request only with a valid access token.                                             | [RFC 6750](https://www.rfc-editor.org/rfc/rfc6750)                                       | [Authentication: Calls to the back-end](docs/authentication.md#calls-to-the-back-end)            |
| `SameSite` cookie          | Cookie attribute that keeps the session cookie off cross-site requests.                                        | [RFC 6265bis](https://datatracker.ietf.org/doc/draft-ietf-httpbis-rfc6265bis/) (draft)   | [Authentication: Signing in](docs/authentication.md#signing-in)                                  |
| Service account            | The `fastprod-backend` client acting as itself to create employees through the Keycloak Admin API.             | [RFC 6749](https://www.rfc-editor.org/rfc/rfc6749#section-4.4) §4.4                      | [fastprod — back-end: Accounts and employees](fastprod-backend/README.md#accounts-and-employees) |
| Single-flight refresh      | One refresh per refresh token, shared by every request of the session that needs it at once.                   | —                                                                                        | [Authentication: The session and refreshing](docs/authentication.md#the-session-and-refreshing)  |
